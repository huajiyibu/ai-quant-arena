# 体检方向 10：产品定位、合规与伦理（评审结果）

> 角色：金融科技产品经理 + 合规/伦理顾问 ｜ 只读定性评审 ｜ 日期：2026-08-13
> 依据：`README.md`、`docs/SRS.md`、`docs/IMPROVEMENTS.md`、`docs/PREDICTION_IMPROVEMENTS.md`、`aitrader/reporter.py`、`aitrader/engines/deepseek.py`、`reports/daily_report.html`、`reports/backtest_report.html`、`config.json`

---

## 1. 结论摘要

1. **产品命题真实且有价值**：对"不懂金融但懂代码"的开发者，"用虚拟资金客观评测 AI 能否盈利"是一个可信、可交付、低风险的命题，且当前实现（三引擎对照、全量留痕、Rank IC 校准、诚实记录方法局限）方法论上明显优于"AI 荐股"类工具。
2. **合规底线当前安全，但存在两个隐患**：纯虚拟资金、不连真实账户、README 顶部 ⚠️ 免责、SRS 明确"不承诺收益/不构成投资建议/不做实盘自动下单"——大方向安全；但**SRS 预留了"真钱半自动建议"接口**，一旦启用即落入证券投资咨询持牌监管，属设计层面的红线隐患。
3. **最大风险是"结论被误读"**：真实盘样本极小（仅 3~4 个交易日、2~3 笔成交），免责声明却只在日报页脚 12px 浅灰小字、远离大字盈亏数字，且完全缺少"模拟≠实盘（滑点/流动性/情绪）"的教育性说明——小白用户极易把"评测结论"读成"AI 会赚钱"。

## 2. 问题清单

### P0-1｜日报免责声明不醒目、远离盈利数字，且头部先放大额基准收益

- **现象**：打开 `reports/daily_report.html`，用户第一眼看到的是页面顶部基准"510300 买入持有 **+32.43%**"，随后是每张卡片内**红色/绿色大字"累计盈亏 -1,092.66 元 / -640.03 元 / -877.57 元"**；免责声明则出现在页面**最底部**一行 12px 浅灰小字。
- **证据**：
  - `reports/daily_report.html` 头部：`基准对照（510300 买入持有，2024-07-22~2026-08-13）：+32.43%`；卡片 `<p class="big">盈亏…<b>-1,092.66 元</b>（-0.11%）</p>`。
  - 页脚：`<p class="foot">本报告为仿真（虚拟资金）结果，仅供学习体验，不构成投资建议。</p>`；样式 `.foot { color:#95a5a6; font-size:12px; }`（`reporter.py` 中 `build_daily_report` 的 HTML 模板，免责声明位于所有卡片与资金曲线图之后）。
  - 同一 `daily_report.html` 中红色大字盈亏与基准之间**没有任何免责/提示**。
- **影响**：对"不懂金融"的目标用户，视觉权重完全倒挂——先看到"赚了/亏了多少钱 + 大盘 +32%"，最后才看到一行灰字"仅供学习"。这直接违背"不误导"的初衷，是本产品最核心的合规/伦理风险。
- **修复建议**：① 免责/教育声明**同时置于页面头部（基准之前）与每张卡片"累计盈亏"旁边**，字号 ≥13px、高对比色（如深灰/橙红）、用边框框起；② 头部基准旁加"此为大盘买入持有参照，非本系统收益"；③ 把免责文本从 12px 灰字升级为固定"警示条"。

### P0-2｜完全缺失"模拟≠实盘"的教育性说明

- **现象**：README 与日报只说"仿真/不构成投资建议"，但**没有一句话解释为什么模拟盈利不能外推到实盘**（滑点、流动性、冲击成本、情绪、真实资金心态、政策时效差异等）。
- **证据**：`README.md` 顶部仅 "⚠️ 本项目是学习/评测工具，不构成投资建议，不保证收益。当前仅仿真，不连接任何真实账户。"；日报页脚同上；全文检索无"滑点/流动性/情绪/实盘"类教育表述（README 仅在 CLI 参数中提 `--slippage`，属功能说明）。
- **影响**：目标用户"不懂金融"，若在某天日报看到"AI 账户 +X% 跑赢大盘"，完全可能产生"模拟盈利 = 实盘可行"的错觉，进而把 AI 输出当实盘操作依据。
- **修复建议**：在 README"免责声明"章节和日报头部各加一段固定教育文案，例如："**模拟≠实盘**：本系统按收盘价成交、默认不计滑点/流动性冲击；实盘还会面临情绪与资金压力，模拟结果不可外推，请勿据此实盘操作。"（日报中成交口径说明 `last_run.json` 的 `fill_note` 已记录"真实盘=收盘价、滑点默认 0"，可顺势引用。）

### P0-3｜SRS 预留"真钱半自动建议"接口 + "真钱体验预算上限 1000 元"

- **现象**：产品文档明确规划了真实资金路径。虽然当前未启用，但这是产品设计上的合规红线隐患。
- **证据**：`docs/SRS.md` §2："系统当前阶段为**纯仿真**（虚拟资金），**预留真钱'半自动建议'模式接口**（不实现实盘自动下单）"；"真钱体验预算上限 1000 元（当前阶段未启用真钱）"。
- **影响**：一旦上线"真钱 + 半自动建议"，就构成面向不特定对象的**证券投资咨询/荐股**行为（《证券法》第一百六十条：证券投资咨询需持牌经营；无牌照机构和个人不得从事），叠加目标用户"不懂金融"，将直接踩红线并可能被认定为非法荐股。即使当前不启用，"预留接口 + 1000 元真钱预算"也说明产品意图未完全切断真钱路径。
- **修复建议**：① 在 SRS 边界（§6）中**明确写入"永不接入真钱/实盘下单/向用户输出实盘操作建议"，并删除"真钱半自动建议"预留接口描述**；② 若坚持保留研究用途，需把该模式限定为"仅限持牌机构或合格投资者评估"，并显著标注"不构成投资建议"——对面向普通开发者的开源工具，建议直接删除。

### P1-1｜极小样本结论未加警示，易被读成"AI 更稳/更赚"

- **现象**：真实盘起点 2026-08-10，仅 3~4 个交易日，三引擎累计成交各 2~3 笔；日报却正常展示"累计盈亏/资金曲线/基准对照"，回测报告甚至出现极端数字"胜率 100.0%、盈亏比 103528.91"。样本如此之小，任何"AI 优于规则/基准"的视觉对比都没有统计意义。
- **证据**：
  - `reports/daily_report.html`：卡片"盈亏（自 2026-08-10 起点归一）"、rule 3 笔 / ai 2 笔 / ai_policy 2 笔；`reporter.py` 中 `_fair_pnl` 用 `FAIR_START_DATE` 归一，但页面无任何"N=2 笔样本"警示。
  - `reports/backtest_report.html`（ai 引擎，11 笔）：`胜率 100.0% ｜ 盈亏比 103528.91`。
  - 内部文档也自认：`PREDICTION_IMPROVEMENTS.md` "样本少（4-11笔）置信度有限"。
- **影响**：用户（尤其小白）会把这个小样本对比当作"AI 能赚钱"的证据，做出错误决策（如跟进、付费、甚至实盘模仿）。
- **修复建议**：① 日报在每张卡片或头部对成交笔数 <20 的账户显著标注"⚠️ 仅 N 笔成交，样本不足，结论不具备统计意义"；② 回测报告的胜率/盈亏比在样本 <30 时加灰显或附样本数警示；③ 引入"至少 N 个交易日/交易才渲染对比结论"的门槛。

### P1-2｜结论可信度污染只对开发者透明，用户不可见

- **现象**：项目内部文档对方法缺陷非常诚实（LLM 记忆污染回测、Rank IC≈0、真实盘与回测口径漂移、真实盘恒无滑点/无止损止盈/无置信度门槛），但用户只看日报/README，**完全看不到这些局限**，会把回测"AI 特征注入 +21.7%"之类的数字当真实能力。
- **证据**：
  - `PREDICTION_IMPROVEMENTS.md`："回测绝对收益可能被模型'记住'（开卷考试）→ 回测绝对收益可能高估、不可外推"；"**Rank IC 全部≈0**（AI 的 confidence 无预测信息量）"。
  - `IMPROVEMENTS.md` P0-2："真实盘以**当日收盘价**成交…回测默认 `fill_mode:next_open`…`config.json` 的 risk 块只暴露 3 字段，`slippage/stop-loss/min_confidence` 用默认值 → **真实盘恒无滑点、无止损止盈、无置信度门槛**"。
  - 上述均写入 `docs/*.md`，日报/README 无对应说明。
- **影响**：用户高估结论可信度、过度依赖系统输出（无法独立判断），与"客观评测"定位相悖。
- **修复建议**：① 在日报增加固定"口径与局限"栏：成交假设（收盘价、滑点 0）、样本数、回测污染说明（模型可能"记住"历史）、Rank IC 含义；② 在"AI 更优"类结论旁强制附带局限声明；③ 把 `PREDICTION_IMPROVEMENTS.md` 的诚实结论（Rank IC≈0、口径漂移）提炼成 README 的"已知局限"公开章节。

### P1-3｜AI 输出的买卖理由/政策解读可能被当专业建议

- **现象**：AI 引擎产出结构化 buy/sell/hold + "一句话理由"，并把财联社政策文本注入提示词；日报展示"今日决策：510300 hold … [其他] 市场震荡…"等理由文本。对不懂金融的用户，这些"AI 决策理由 + 政策参考"看起来就是荐股/宏观解读。
- **证据**：`aitrader/engines/deepseek.py` `_system_prompt()`："你是 AI Quant Arena 的量化决策助手…"；`_build_prompt()` 注入"今日宏观政策/要闻（供参考：请甄别其对市场的真实影响，警惕利好出尽…）"并输出 `{"action":"buy","reason":"[趋势] 放量突破20日线"}`；日报 `dec_line = f"<p>今日决策：…{reason}"`（`reporter.py`）。
- **影响**：政策/理由内容本身可读、可截图传播，脱离"虚拟盘评测"语境即成为"AI 看好的方向/理由"，存在被认定为变相荐股或误导的伦理风险。
- **修复建议**：① 日报"今日决策"区加固定前缀"**以下为仿真引擎算法输出，非投资建议，仅供评测观察**"；② 政策段落注明"来源：财联社，仅供研究，已按关键词过滤，非完整信息"；③ 系统提示词明确"你不对任何人构成投资建议"。

### P2-1｜API 成本与数据源风险未对用户透明（可持续性）

- **现象**：API 成本由用户自有 DeepSeek Key 承担，`last_run.json` 不累计 API 调用/费用（内部 P1-6 未落地）；数据源依赖免费的 akshare + 财联社，稳定性风险（已有超时/重试/IPv6 过滤加固）。
- **证据**：`IMPROVEMENTS.md` P1-6："`last_run.json` 不记 API 调用次数与估算费用"；`README.md`："API 响应会缓存到 `data/ai_response_cache.json`（上限 2000 条，防无限膨胀），重复回测不重复计费"；`config.json` `base_url: https://api.deepseek.com`、`policy` 财联社关键词。
- **影响**：规模化前成本不可见、数据源可能中断，影响"免费工具"的可持续承诺；用户可能低估长期运行的真实成本。
- **修复建议**：① 落地 P1-6：`last_run.json` 累计 API 调用数与估算费用，日报页脚展示"本月 API 成本"；② README 明确数据源免费但不保证可用性，给出降级预案说明。

### P2-2｜定位表达存在"产品化 vs 评测工具"张力

- **现象**：README 标题是"AI 自动交易**体验机**"，"怎么看结果"称日报"小白友好"；SRS 定位是"学习体验 + 客观评测 AI 决策能力"。命名与"评测/研究工具"定位有偏差，容易让用户期待"会赚钱的产品"而非"评测实验"。
- **证据**：`README.md` 标题"# AI 自动交易体验机"；"怎么看结果"："大字显示累计盈亏、持仓、资金曲线，**小白友好**"；`docs/SRS.md` §2："本项目价值 = 学习体验 + 客观评测 AI 决策能力，不承诺任何收益"。
- **影响**："体验机 + 小白友好 + 大字盈亏"的体验强化"收益产品"心智，弱化"严谨评测"心智，进一步放大前几条的误读风险。
- **修复建议**：① 统一命名与定位表述（如"AI 量化决策评测工具"），弱化"体验机/赚钱"措辞；② 在 README 首屏明确"这是给开发者做 AI 交易能力评测的研究工具，不是理财产品"；③ 日报标题从"AI 交易日报"改为"AI 决策评测日报"。

## 3. 做得好的地方

1. **合规态度端正**：README 顶部 ⚠️ 免责 + 底部"仅供技术学习与策略研究，不构成任何投资建议"；SRS 明确"不承诺收益、不构成投资建议、不做实盘自动下单"；纯虚拟资金、不连接真实账户、API 密钥走 `.env` 不入库——基本合规框架是齐全的。
2. **对方法缺陷诚实（内部）**：LLM 记忆污染回测、Rank IC≈0、样本小、真实盘/回测口径漂移等局限全部如实记录在 `PREDICTION_IMPROVEMENTS.md` / `IMPROVEMENTS.md`，且风控写死（单笔≤30%、单日≤50%），符合"客观评测"的初心，工程与评测方法论显著优于"AI 荐股"类产品。
3. **评测闭环自证能力强**：日报已带 Rank IC 校准、信心分桶胜率、数据截至日期陈旧警示、归因复盘——系统在"让结论可被质疑、可被验证"上比大多数同类型工具克制得多。

---

## 4. 一句话总结

作为面向个人开发者的"AI 能否盈利"仿真评测/学习工具，**命题真实、方法论诚实、当前纯仿真合规安全，产品可行**；但只要样本放大前仍"大字盈亏 + 页脚小字免责 + 无模拟≠实盘教育 + 预留真钱接口"，它就会被读成"AI 会赚钱"，因此**必须先补齐 P0-1/P0-2/P0-3 三项护栏，且现阶段应定位为个人研究工具而非面向大众的产品**。
