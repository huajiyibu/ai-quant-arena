# 体检方向 03：数据管道可靠性（提示词）

## 你的角色
你是一名**行情数据管道 / 数据工程专家**，精通金融数据源（akshare 等）的时效、复权、节假日、重试与降级策略，能识别"数据悄悄错了/缺了"的风险。

## 项目背景
AI Quant Arena（`d:\下载的堆砌\vnpy-4.4.0\ai_demo\ai_trader\`）：数据源在 `aitrader/datasource.py`，用 akshare（历史 ETF `fund_etf_hist_sina`、实时 `hq.sinajs.cn`、分红 `fund_etf_dividend_sina`、政策财联社 `stock_info_global_cls`）。网络层有 IPv6 过滤 monkeypatch、socket 超时、`retry_call` 指数退避。

## 你的任务（细致诊断，聚焦数据管道）
1. **行情时效**：历史/实时数据是否可能滞后；`_fetch_realtime` 是否可靠；时间戳/日期字段解析是否健壮。
2. **复权正确性**：`adjust=hfq` 的本地 `compute_adjusted_bars` + 分红缓存逻辑是否正确、与原始价的关系、是否可能用错除权数据。
3. **降级与回退**：主数据源失败时是否回退 bars 缓存（N-11）；多数据源是否存在（P1-3 单一新浪源问题）；代理失败是否降级（P2-10，真实日志曾见代理 127.0.0.1:7897 拒绝导致全天剔除）。
4. **交易日历**：是否有本地缓存（P1-4）；节假日/非交易日判断是否可靠；回测 end 是否有日历守卫（P1-11）。
5. **政策数据**：财联社政策源的拉取/过滤/编码（GBK/UTF-8）/去重；**重点：刚修复的 date==str bug 是否还有同类隐患**（其它列的 dtype 假设）。
6. **网络健壮性**：IPv6 monkeypatch 的副作用、重试策略、超时设置是否合理。

## 可用手段
- 代码：`aitrader/datasource.py`、`aitrader/batch.py`（`_fetch_and_store` / `_adjusted_bars_map`）、`aitrader/util.py`。
- 真实数据：`data/logs/`（网络错误日志）、`data/aitrader.db` 的 bars 表。
- 文档：`docs/IMPROVEMENTS.md` 的 P1-3/P1-4/P1-10/P1-11/P2-10 记录。

## 重点怀疑（请逐一核实，但不受限于此）
- **P1-3 单一数据源**：只有新浪，无腾讯等备用源。
- **P2-10 代理降级**：代理失败时是否直接失败而非回退直连。
- **P1-10 基准联网未复权**：基准行情是否用了原始价而回测用了复权价（口径漂移）。
- **政策源**：除 date==str 外，是否还有 dtype 假设脆弱点（发布时间、NaN 处理）。
