## 通用背景（所有 Agent 共用）

- **项目**：AI Quant Arena（`d:\下载的堆砌\vnpy-4.4.0\ai_demo\ai_trader\`）——客观评测"AI 能否通过**模拟交易**盈利"的实验系统，**绝不承诺实际收益**。
- **引擎**：rule（规则）/ ai（DeepSeek）/ ai_policy（AI+宏观政策）三引擎，各 100 万虚拟初始资金独立跑批，每日 15:30 定时任务。
- **数据**：akshare（历史 ETF `fund_etf_hist_sina` / 实时 `hq.sinajs.cn` / 分红 / 财联社政策）。
- **存储**：SQLite `data/aitrader.db`（trades / decisions / daily_snapshots / batch_runs / account_states / bars）。
- **测试**：`tests/` 共 197 个，用 `C:\veighna_studio\python.exe -m pytest tests -q` 跑。
- **文档**：`docs/IMPROVEMENTS.md`（历史评审与待办，**含大量已知问题线索，请核实**）、`README.md`、`docs/SRS*.md`、`docs/DESIGN*.md`。
- **真实运行**：`data/logs/`、`data/last_run.json`、`data/aitrader.db`（2026-08-13 已全量重置为空账本，备份在 `data/aitrader_backup_20260813_1630.db`）。
- **版本现状**：v0.22，最新提交 `44be281`；当前工作区应干净（`git status` 应无改动）。

## 输出要求（所有 Agent 通用）

诊断结果写入 `result/` 下对应文件（`result/NN_xxx.md`），格式：
1. **结论摘要**（3 条以内，直击要害）
2. **问题清单**：按严重性 P0（致命）/ P1（重要）/ P2（建议）分级，每条含：现象 → 证据（文件:行号 或 具体数据/日志）→ 影响 → 修复建议
3. **做得好的地方**（2~3 条，别全盘否定）
4. **一句话总结**

⚠️ 纪律：只读不改；证据优先，不接受无证据的猜测；不写代码、不改任何文件（除了自己的诊断报告）。
