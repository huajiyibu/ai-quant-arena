# AI Quant Arena · 需求说明书 (SRS)

| 项目 | 内容 |
|---|---|
| 版本 | 1.3 |
| 日期 | 2026-08-12 |
| 状态 | 已评审（用户拍板）；代码已迭代至 v0.18（184 用例全过） |

## 1. 项目概述

构建一个 **AI 驱动的自动化交易仿真系统**，让金融零基础的用户以**零风险**方式体验量化交易全流程，并通过**长期留痕**客观评估"AI 决策"的真实水平。

> ⚠️ 本项目价值 = 学习体验 + 客观评测 AI 决策能力，**不承诺任何收益**，不构成投资建议。

## 2. 背景与定位

- 用户为软件开发工程师，金融知识为零，真钱体验预算上限 1000 元（当前阶段未启用真钱）。
- 系统当前阶段为**纯仿真**（虚拟资金），**预留真钱"半自动建议"模式接口**（不实现实盘自动下单）。
- 解决的核心痛点：用户想用 AI 自动交易，但需要先以安全方式验证"AI 到底行不行"。

## 3. 术语

| 术语 | 定义 |
|---|---|
| 引擎 (Engine) | 生成交易决策的组件。本系统含三个引擎：`AI·纯价格`、`AI·价格+政策`（均 DeepSeek）与 `规则引擎`（内置双均线） |
| 特征 (Feature) | 由代码精确计算的技术指标（MA/RSI/动量/波动率/距高/量比）注入提示词，替代模型心算漂移 |
| 复权 (Adjust) | 把除权分红加回价格（`hfq` 后复权式），消除除权日跳空，保证指标连续 |
| 双 bars | 真实盘特征用复权价、估值/成交用原始价的双套行情（N-1） |
| 置信度 (Confidence) | AI 对决策的正收益信心（0~1），用于门槛过滤与 Rank IC 校准 |
| Rank IC | AI 置信度与后续实际收益的 Spearman 相关，衡量"信心是否预测得准" |
| 货基利息 | 空仓现金按年化利率（默认 1.7%）每日计息，模拟真实账户闲置资金收益 |
| 账本 (Account) | 独立仿真账户，含现金、持仓、盈亏，可追溯 |
| 批处理 (Batch) | 每个交易日收盘后执行一次的完整流程 |
| 决策 (Decision) | 引擎输出的结构化操作指令（buy / sell / hold） |

## 4. 功能需求 (FR)

| 编号 | 需求 | 说明 |
|---|---|---|
| FR1 | 每日批处理 | 交易日收盘后运行一次：拉行情 → 多引擎决策 → 风控 → 执行 → 记账 → 报表；非交易日跳过；同日重复运行幂等（不重复成交） |
| FR2 | 多引擎并行 | 规则 / AI·纯价格 / AI·价格+政策 各跑独立账本，数据共享，结果可对比 |
| FR3 | 行情获取 | akshare 拉取配置标的日线；数据源可注入（便于测试 mock） |
| FR4 | AI 决策 | 调用 DeepSeek API，结构化 JSON 输出；超时/失败自动降级并留痕 |
| FR5 | 规则决策 | 内置双均线策略作为基线，与 AI 形成对照 |
| FR6 | 风控 | 单笔买入 ≤ 总资产 30%；单日累计买入 ≤ 总资产 50%；现金约束；A股一手整数（100 股）；手续费万 2.5 |
| FR7 | 持久化 | SQLite 全量留痕：账户、每日净值快照、成交记录、决策记录（含喂给引擎的原始行情与引擎原始输出） |
| FR8 | 报表 | 双账户资金曲线对比图（PNG）；文本周报（可选） |
| FR9 | 配置与密钥 | pydantic 配置模型；API 密钥走 `.env`，不入库、不入仓、不落日志 |
| FR10 | CLI | `run.py` 支持 `--engine` 选择引擎、`--date` 指定交易日（回放，只取截至该日行情、无前视偏差）、`--force` 强制重跑、`--report-only` 仅出报表 |
| FR11 | 部署 | Windows 定时任务注册/卸载脚本，交易日自动运行 |
| FR12 | 政策参考引擎 | 第三个引擎“AI·价格+政策”：每日拉取宏观政策快讯（财联社电报），按关键词过滤后注入 AI 提示词，与“AI·纯价格”“规则”三方对比 |
| FR13 | 交易日与幂等 | 非交易日自动跳过批处理（交易日历判断，失败降级为仅跳过周末）；同一账户同一天只处理一次，定时任务 + 启动项兜底同日重复触发时不重复成交 |
| FR14 | 回测与评估 | `--backtest` walk-forward 回测：独立数据库逐日回放引擎历史决策，输出年化收益、最大回撤、夏普、胜率、盈亏比、换手率等指标，并与基准（配置首个标的买入持有）对比，生成净值曲线 + 回撤图与指标日报；回测默认跳过政策版引擎（无历史政策源，会退化为纯价格版）；Rank IC 只统计实际成交的买入 |
| FR15 | 特征注入 | 提示词注入确定性技术指标（MA/RSI/动量/波动率/距高/量比），代码精确计算；真实盘特征用复权价（双 bars） |
| FR16 | 复权 | 回测与真实盘支持后复权式调整（`adjust=hfq`，分红加回），消除除权跳空，与回测口径一致 |
| FR17 | 置信度门槛 | AI 输出每笔决策置信度；`min_confidence_buy` 低于门槛的买入被风控拒绝并留痕 |
| FR18 | Rank IC 校准 | 真实盘对已满 20 交易日窗口的**实际成交**买入回填后续收益，计算置信度 Rank IC，日报展示累计 IC 与按信心分桶胜率 |
| FR19 | 市场环境注入 | 可选把市场温度（距高点/20日涨跌/波动率/RSI）注入提示词；A/B 验证（夏普 0.98→1.57、回撤 10%→2.9%）后默认开启 |
| FR20 | 历史盈亏反馈 | 可选把近 N 笔已平仓交易及盈亏注入提示词供模型复盘（`--feedback N`，默认关） |
| FR21 | 止损/止盈 | 可选强制止损/止盈（`stop_loss_pct`/`take_profit_pct`）；rule 网格实验无有效组合，默认关 |
| FR22 | 现金生息 | 空仓现金按年化利率每日计息（`cash_interest_rate`，默认 1.7%），快照记录每日利息，日报展示累计货基利息 |
| FR23 | 补跑 catch-up | `--catch-up [N]` 从最近快照次日补齐缺失交易日（幂等不重复成交）；部署启动项已接线 |
| FR24 | 通知 | `notify` 配置（webhook）下，批处理失败/连续无成交/净值回撤超阈值时推送告警（默认关，跨全部引擎判定） |
| FR25 | 滑点 | 回测支持 `slippage_bps` 双边滑点建模（默认 0） |
| FR26 | 归因复盘 | 决策理由以 [标签] 开头（趋势/回调/政策/超买/超卖/其他），日报按标签聚合已平仓配对盈亏（净口径含佣金） |

## 5. 非功能需求 (NFR)

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR1 | 可测试性 | 风控/账本/规则引擎/解析等核心逻辑为纯函数或可注入依赖，配 pytest 用例 |
| NFR2 | 可审计性 | 每个决策保留"输入行情 + 输出建议 + 执行结果"，可回放 |
| NFR3 | 可靠性 | 外部 API 失败不中断整体流程，自动降级并记录 |
| NFR4 | 性能 | 单次批处理 ≤ 60 秒 |
| NFR5 | 安全 | 密钥仅存本地 `.env`，`.gitignore` 排除 |
| NFR6 | 可维护性 | 模块化分层、类型注解、统一 logging |
| NFR7 | 运行留证 | 日志落盘 + `last_run.json` + 单实例锁，定时任务下可留证、防并发重复成交 |
| NFR8 | 数据时点硬校验 | 参与决策/估值的标的最新行情必须为决策当日（bar_date==date），陈旧剔除并告警，杜绝"用旧价假装当日" |
| NFR9 | 政策防前视 | 政策仅取决策日 15:30 前发布（截止时点截断），避免用收盘后消息 justify 收盘成交 |
| NFR10 | 网络健壮 | 所有外部请求带超时 + 指数退避重试；IPv6 过滤（国内源优先 IPv4）；实时行情接入重试 |
| NFR11 | 计息幂等 | 现金生息按 `last_interest_date` 幂等，`--force`/崩溃重跑不双计息 |
| NFR12 | 可观测记账 | `last_run.json` 记录各引擎 API 调用量/缓存命中、成交口径说明（fill_note）；失败路径保留上次成功记录 |
| NFR13 | 实验台账 | 回测/实验参数与 A/B 结论记录到 `PREDICTION_IMPROVEMENTS.md`，可追溯对比（当前人工维护） |

## 6. 边界（明确不做）

- 不做实盘自动下单（仅预留接口）。
- 不做盘中实时交易（仅收盘批处理）。
- 不做 Web / 移动端 UI。
- 不提供收益承诺与投资建议。
